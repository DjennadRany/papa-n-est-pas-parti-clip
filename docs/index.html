🎬 Studio Clip IA

Tableau de production local : prépare ton scénario, ton audio, tes images et tes séquences IA. L'interface ne téléverse rien à ton insu.

1. Préparer un nouveau projet

Le manifeste contient les noms de fichiers et les consignes, pas les médias eux-mêmes. Pour lancer les calculs, importer ensuite les fichiers dans le dépôt GitHub.

2. Production des plans

Chaque plan peut venir d'un moteur IA différent ou être ajouté manuellement. Le montage accepte des MP4, quelle que soit leur origine.
